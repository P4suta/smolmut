# Smolmut

Mutation testing for Gleam through a library and CLI.

## Installation

```sh
git clone https://github.com/P4suta/smolmut.git
cd smolmut
mise run bootstrap
```

## Usage

```sh
mise x -- gleam run -m smolmut -- --help
```
